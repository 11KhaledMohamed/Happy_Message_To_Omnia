# دعوة تفاعلية — خالد وأمنية

## المحتويات
- مقدمة بصورة شخصية وعبارة `The Most Beautiful Girl ❤️`.
- معرض صور يحتوي على الصور الثماني المرسلة.
- تكبير الصور عند الضغط عليها.
- رسالة ختامية.

تم استبعاد العد التنازلي والرسائل التفاعلية وسؤال القلب والمؤثرات الإضافية حسب المطلوب.

## الصور
- `assets/main-photo.jpg`: الصورة الرئيسية.
- `assets/gallery-1.jpg` إلى `assets/gallery-8.jpg`: صور المعرض بالترتيب الذي أُرسلت به.

## التشغيل والنشر
افتح `index.html` لمعاينة الموقع.
للنشر على Vercel: ارفع محتويات المجلد إلى GitHub ثم اربط المستودع بـ Vercel. اختر Framework Preset = Other، واترك Build Command فارغًا.


## الموسيقى
تمت إضافة `assets/background-music.mp3` مع زر تشغيل/إيقاف ثابت أسفل الشاشة.
يبدأ التشغيل بعد ضغط الزائر على الزر؛ لأن المتصفحات تمنع غالبًا تشغيل الصوت تلقائيًا دون تفاعل.


## شاشة الدخول
عند فتح الرابط تظهر شاشة افتتاحية هادئة بزر "افتحي الدعوة".
ضغطة الزائر تفتح الدعوة وتحاول تشغيل الموسيقى مباشرةً ضمن نفس التفاعل، بما يتوافق مع قيود تشغيل الصوت في المتصفحات.
